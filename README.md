# Duesy

Duesy는 대학 동아리 총무를 위한 회비·지출 관리 SaaS MVP입니다. 회원별 납부 상태와 지출 내역을 한곳에서 관리하고, 개인정보를 제외한 읽기 전용 장부를 구성원에게 보여줍니다.

## 해결하려는 문제

동아리 총무는 계좌 내역, 회원 명단, 영수증, 메신저 공지를 따로 관리하는 경우가 많습니다. 이 과정에서 납부자 확인이 반복되고 장부 잔액이 어긋나며, 구성원에게 전체 내역을 설명할 때 학번이나 미납 상태 같은 개인정보가 함께 노출될 수 있습니다.

Duesy는 다음 흐름을 한 화면에 연결합니다.

1. 회원 이름이나 학번으로 검색하고 회비 납부 여부를 변경합니다.
2. 사용처, 분류, 금액, 메모를 입력해 지출을 등록합니다.
3. 납부 수입과 누적 지출을 기준으로 현재 잔액을 자동 계산합니다.
4. 개인 정보가 빠진 구성원용 공개 장부를 확인합니다.

## 데모

- 배포 사이트: 배포 후 이 README에 추가
- ID: `demo@duesy.app`
- PW: `duesy2026`

로그인 후 다음 검증 흐름을 권장합니다.

- `회비 관리`에서 미납 회원을 납부 완료로 변경
- `지출 내역`에서 새 지출 등록
- 대시보드의 납부율, 잔액, 최근 지출이 변경됐는지 확인
- `공개 장부`에서 개인정보가 제외되고 새 지출이 반영됐는지 확인
- `데모 초기화`로 기본 데이터 복원

## 구현 범위

- Next.js 16 App Router, React 19, TypeScript
- 반응형 랜딩 페이지, 데모 로그인, 제품 대시보드
- 회비 회원 검색과 납부/미납 필터
- 납부 상태 변경과 합계 자동 갱신
- 지출 등록 모달과 최근 지출·잔액 자동 갱신
- 구성원용 공개 장부
- 버전이 지정된 localStorage 기반 데모 상태 보존 및 초기화
- 접근 가능한 폼 레이블, 키보드 사용 가능한 버튼, 모바일 내비게이션

## 의도적으로 제외한 범위

해커톤 MVP의 검증 범위를 명확히 하기 위해 서버 데이터베이스, 실제 계좌 연결, 영수증 OCR, 다중 동아리, 초대와 권한 관리는 구현하지 않았습니다. 현재 인증은 공개 데모 체험을 위한 클라이언트 세션이며 실제 서비스 인증으로 사용할 수 없습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.
