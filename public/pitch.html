DWNC Hackathon · Team Real

Duesy.

대학 동아리 총무가 회비 납부와 지출을 한곳에서 관리하고, 구성원에게 이해하기 쉬운 장부를 공유하는 웹 SaaS입니다.

Problem

회비 내역은 흩어지고
설명 책임은 총무에게 남습니다

납부 확인

계좌 내역과 회원 명단을 오가며 수기로 대조합니다.

지출 기록

영수증과 메신저 기록이 분리되어 잔액이 자주 어긋납니다.

공개 부담

전체 장부를 공개하면 학번과 납부 상태까지 노출될 수 있습니다.

Solution

총무 화면과 공개 장부를
하나의 데이터 흐름으로 연결

1. 회비 관리회원 검색, 납부 상태 변경, 납부율 자동 계산
2. 지출 등록사용처와 금액 입력 즉시 잔액과 최근 지출 갱신
3. 공개 장부개인정보를 제외한 읽기 전용 내역 제공
Implementation

브라우저에서 끝까지
검증 가능한 MVP

Next.js 16

App Router와 React 19로 반응형 제품 화면을 구현했습니다.

실제 상호작용

납부 처리와 지출 등록이 모든 합계와 장부에 즉시 반영됩니다.

데모 지속성

버전이 지정된 localStorage에 상태를 보존하고 초기화 기능을 제공합니다.

Current result
1 flow

로그인부터 공개 장부까지

데모 계정으로 접속해 회원의 납부 상태를 바꾸고 새 지출을 추가한 뒤, 잔액과 공개 장부가 함께 갱신되는 과정을 확인할 수 있습니다.

한계: 현재는 단일 동아리 데모이며 서버 DB, 실제 계좌 연동, 다중 권한은 구현하지 않았습니다.
